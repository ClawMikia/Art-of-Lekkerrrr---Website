# 3D UI + particle FX (Website)

Unzip over the project (same paths). Layout/positions are unchanged: only transforms, shadows, opacity and overlays were added.

- `css/fx.css` (new): depth shadows, glossy bevels, 3D buttons, entrance slide/scale/fade, modal pop-in/out, page transition.
- `js/fx.js` (new): ambient particle motes, burst particles (win confetti, lose embers + shake, unlock stars), pointer tilt + glare, modal exit animation, sound-synced sparks.
- `index.html`, `trophy-room.html`: one `<link>` and one `<script>` added.

Toggle effects: round **FX** button (bottom-right) or press **E**. Off by default if the OS requests reduced motion; choice is remembered.
